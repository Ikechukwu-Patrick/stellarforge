# StellarForge

[![Go Version](https://img.shields.io/badge/Go-1.22+-00ADD8?logo=go)](https://go.dev/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

StellarForge is an open-source Go toolkit for building secure, production-ready applications on the Stellar blockchain.

## 🎯 Project Goal

StellarForge aims to provide Go developers with reusable, well-tested utilities for building applications on the Stellar blockchain. The project is designed to simplify common Stellar development tasks through clean, modular packages.

## ✨ Current Features

- ✅ Stellar address validation
- ✅ Unit tests
- ✅ Modular Go project structure
- ✅ MIT License
